# Mnv - Personal Portfolio

![Status](https://img.shields.io/badge/status-production-2ea44f?style=flat-square) [![Live site](https://img.shields.io/badge/live-mnvv.netlify.app-000000?style=flat-square)](https://mnvv.netlify.app)

Welcome to the personal portfolio website of **Manav**. This repository hosts the source code for my personal website, showcasing my work, books, and thoughts.

## 🚀 About

Manav is a B.Tech CSE (AI & ML) student passionate about understanding systems—both technological and human. This website serves as a digital garden for:
- **Books:** Detailed information about my writing, including "What Stayed".
- **Other Work:** A collection of professional and personal projects.
- **Thoughts & Philosophy:** distinct perspectives on growth and mastery.

## 🛠️ Tech Stack

- **HTML5:** Semantic structure for accessibility and SEO.
- **CSS3:** Custom styling with responsive design, flexbox, and grid layouts.
- **Google Fonts:** Typography utilizing the 'Montserrat' and 'Georgia' font families.

## 📂 Project Structure

- `index.html`: The main landing page.
- `styles.css`: Global stylesheets and responsive definitions.
- `books.html`: Catalog of published books.
- `what-stayed.html`: dedicated detail page for "What Stayed".
- `about.html`: Personal biography and background.
- `contact.html`: Contact form and social links.
- `assets/`: Directory containing images and other static assets.

## 📦 How to Run

To view this website locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/manav-Mnv/M-N-V---webpage.git
   ```
2. Navigate to the project folder:
   ```bash
   cd M-N-V---webpage
   ```
3. Open `index.html` in your preferred web browser.
